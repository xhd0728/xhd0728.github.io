forked from [acad-homepage](https://github.com/RayeRen/acad-homepage.github.io)

```shell
# install
bundle install

# local preview only
bundle exec jekyll serve

# production build
JEKYLL_ENV=production bundle exec jekyll build

# validate generated links, bilingual content, metadata, and icons
python3 scripts/check_site.py
```

The icon fonts are checked-in WOFF2 subsets. After adding an icon, install the optional
`fonttools[woff]` authoring dependency and run `python3 scripts/subset_icon_fonts.py`.
Keep the corresponding selector in `_sass/vendor/font-awesome/_icons-subset.scss`.

GitHub star badges in News, projects, and publications are saved locally so they remain visible without a third-party
request. Run `python3 scripts/update_github_star_badges.py` to refresh them; the publishing
workflow also refreshes them before each build and keeps saved badges if the service is unavailable.

Other resource links use the standard Shields.io `flat` style, also stored locally.
Their shared labels, full DOI identifiers, icons and colors live in `_data/resource_badges.json`.
Colors distinguish resource types: arXiv red, Hugging Face yellow, Homepage blue,
Docs teal, Demo green, and DOI orange.
After changing them, run `python3 scripts/build_resource_badges.py` to regenerate the SVGs.

For the optional browser regression suite, install Playwright without changing the
Ruby build (`npm install --no-save --package-lock=false playwright`, then
`npx playwright install chromium webkit firefox`). Serve `_site` locally and run:

```shell
python3 -m http.server 4173 --bind 127.0.0.1 --directory _site
# In another terminal; outputs screenshots and JSON to a temporary directory.
node scripts/browser_smoke.cjs
```

`SITE_URL` and `REPORT_DIR` override the preview URL and artifact directory. The suite
blocks third-party requests and checks both languages at eight viewport widths,
keyboard interaction, language navigation, image previews, and no-JavaScript fallback.
Run `node scripts/browser_compat.cjs` for the additional keyboard, history,
short-window, landscape, and unavailable-dialog regression cases.

Paper/project thumbnails can be rebuilt with `python3 scripts/build_thumbnails.py`
(optional dependency: Pillow). The 400/640/800 px files are generated from the
full-size originals, which are preserved for image previews.

The Chinese fallback is an OFL-licensed Noto Sans SC subset with a content-hashed
filename. After adding Chinese text, the validator checks its character coverage.
To rebuild, download the [source TTF](https://github.com/google/fonts/raw/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf)
and run `python3 scripts/subset_chinese_font.py /path/to/NotoSansSC.ttf` using the
optional `fonttools[woff]` dependency. The generated font and coverage manifest
are checked in; normal builds do not download or regenerate fonts.

Do not deploy the `_site` output generated by `jekyll serve`. Use the production build or the GitHub Actions workflow output instead.

Production deployment is handled by GitHub Actions:

- Push to `main`
- Workflow builds the site into `_site`
- Workflow force-pushes the built output to the `cloudflare-pages` branch
- Cloudflare Pages should use `cloudflare-pages` as the production branch

Recommended Cloudflare Pages settings for this repo:

- Production branch: `cloudflare-pages`
- Preview branch control: `None`
- Build command: leave blank
- Build output directory: `.`
- Custom domain: `https://xinhaidong.top`
